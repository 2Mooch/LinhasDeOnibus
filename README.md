# Sistema de Itinerário de Ônibus

## Descrição
Este projeto corresponde ao setup inicial de um sistema de gerenciamento de rotas de ônibus em C++. A proposta utilizará listas encadeadas para representar as paradas da rota.

## Requisitos
- GCC/G++ versão 11 ou superior
- Visual Studio Code com extensão C/C++
- Terminal para execução

## Compilação e Execução

### Compilar
```bash
g++ main.cpp -o programa
```

### Executar
```bash
./programa
```

### Testes
```bash
g++ tests/test.cpp -o teste
./teste
```
